# README

This project is a repository of Dungeons & Dragons 5th Edition homebrew monsters I created for the Halloween Zero-to-Thirty Challenge Rating Challenge (#030crc).

See https://wavebirddash.github.io/dnd5e-030crc for a published browsable webpage. This repository is a GitHub-managed version of the published page. Feel free to contribute to this project by submitting issues or pull requests.
